===========
-1- general
===========
PIL is generally split into modules that should be imported as needed.
Common modules are: Image|ImageTk|ImageDraw|ImageFont

from PIL import ...

Sizes are always width,height.

coordinates are always x (leftright),y (updown)

===========
-1.0- Image
===========
Image.Image is the basic image class.

Empty images can be created with Image.new(mode, size)


-----
attrs
-----
height: int
width: int
size: (width, height)
format: file extension

-------
methods
-------
open(fname): lazy open a file as Image
save(fname, format, options):
	format: JPEG|PNG|BMP
crop((l,t,r,b)):
	Return a view on region
load():
	allocate and load data.
	(if a view, will allocate and own data.)
paste(Image, region, alpha):
	paste image into self.
	Image: pil image or pixel value
	region: (l,t) or (l,t,r,b)
	alpha: for pasted transparency

split():
	return channels

resize(shape)
rotate(deg, resample, expand):
	Retrun a rotated copy.
	deg: degrees, counter-clockwise
	resample: Image.NEAREST|BILINEAR|BICUBIC
	expand: true/false:
		expand size to contain entire rotated image
		or otherwise, maintain shape and crop corners.

transpose(Image.FLIP_LEFT_RIGHT|FLIP_TOP_BOTTOM|ROTATE_90|ROTATE_180|ROTATE_270)
	Return a transposed copy

transform(size, method, data, resample,fill):
	size: output size
	method: Image.EXTENT|AFFINE|PERSPECTIVE|QUAD|MESH
		EXTENT seems to just be cropping or an IamgeTransformHandler
	data: the transform info
	resample: resampling methods NEAREST|BILINEAR|BICUBIC
	fill: ?an arg for ImageTransformHandler? if method was that
	fillcolor: background fill color

convert(mode, matrix, dither, palette, colors)
	matrix: 4 or 12-tuple (matmul to get a new pixel)
	dither: use dithering, NONE|FLOYDSTEINBERG
	palette: palette to use for conversion or WEB|ADAPTIVE
	colors: number of colors for adaptive palette

filter(filt):
	run an ImageFilter on image.



===========
-1.1- modes
===========
main modes:
	1: 1-bit black/white image
	L: 8-bit gray
	P: 256-colors with color palette
	RGB: 24-bit px
	RGBA: 32-bit px
	CMYK
	YCbCr
	LAB
	HSV
	I: 32-bit int pixels
	F: 32-bit float pixels
alt modes:
	LA: L with alpha
	PA: P with alpha
	RGBX: RGB with padding
	RGBa: premultiplied alpha
	La: L with premultiplied alpha
	I;16: 16-bit uint px
	I;16L: 16-bit little endian uint px
	I;16B: 16-bit big endian uint px
	I;16N: 16-bit native endian uint px

===============
-1.2.1- anchors
===============
Text uses anchors for where to align text relative to coordinate.
Generally this is a 2-letter code with left/right and top/bottom anchors.

----------
left/right
----------
l: left
m: middle
r: right

----------
top/bottom
----------
t: top
m: middle
b: bottom (eg. bottom of g)


left/right text only: (as opposed to vertical, like chinese)
a: ascender (top of first line of text, if multiline)
s: baseline (line that text would be written on)
d: descender (bottom of last line of text (multiline))


=============
-1.2.2- fonts
=============
PIL.ImageFont

Generally, fonts are stored in some file under some default system dirs:
	/usr/share/fonts/
	C:\Windows\Fonts

PIL will generally search these dirs automatically so only the basename
is really necessary.  Furthermore, it seems to search extensions too
so only the base name without extension is needed at minimum.

Generally use ImageFont.truetype(filename, size) to get a loaded font.


-----
attrs
-----
index: index in font file (ttc)
path: filepath to font
size: font size

--------------
Useful Methods
--------------

font_variant(*, size=10, index=0, encoding='', layout_engine=None)
	Get a variation of the current font (ex. change font size)
getbbox(text, mode='', direction=None, features=None, language=None, stroke_width=0, anchor=None)
	Return bounding box (l,t,r,b)
	direction: 'rtl'|'ltr'|'ttb'
	language: BCP 47 language code
	anchor: -1.2.1- text anchor
getlength(text, mode, direction, features, language)
getmetrics() -> (ascent, descent) (base->highest, base->lowest)

getmask(text, mode, direction, features, language, stroke_width, anchor, ink, start):
getmask2(text, ...)
	make a bitmap for text
getname()

-------------
other methods
-------------

===========
-2.1- numpy
===========
PIL can be converted to/from numpy, BUT only via copies.

pilimage = Image.fromarray(npimage)

npimage = np.asarray(pilimage)
npimage = np.array(pilimage)

NOTE: asarray is read-only BUT it does not seem to share the buffer.
Taking np.asarray(pim) gives a read-only view but the view
does not reflect any changes after the view was already taken.
The only alternative is that pil drawing functions re-allocate
the buffer which doesn't really make any sense.

========

image handling, taking a pill image as argument.

PhotoImage(pilim)
