	"model": "gemma3:4b",
	"prompt": "Explain the concept of recursion with a simple example",
	"stream": false
}'

	"model": "gemma3:4b",
	"messages": [
		{"role": "user", "content": "What are the benefits of using Gemma 3 over other language models?"}
	],
	"stream": false
}'

============
-2.1.0-  api
============
https://docs.ollama.com/api/introduction

Ollama is structured as server/client.  The server runs the models.
Clients connect to the server and send requests.

The server provides REST APIs for clients to use on port 11434 by default.
Generally requests and responses are in json format (or concatenated json)

______________________
General request fields
{
	"model": "name of the model to use"
	"stream": true/false (false: response = application/json | true: response = application/x-ndjson)
	"options": {
		"seed": int,
		"temperature": float, 0=norandom, 1=highrandom
		"top_k": int
		"top_p": float, cum prob for "nucleus sampling"
		"min_p": float, min prob thresh for token selection
		"stop": "stop sequence that will halt generation"
		"num_ctx": int, length of context (tokens)
		"num_predict": int, num tokens to generate
	},
	"logprobs": bool, return log probs of output tokens?
	"top_logprobs": int: number of likely tokens
	"format": "json" or json schema object,
	"think": true/false | "high|medium|low|max"
	"keep_alive": "model-keep-alive duration, ex: 5m, 0"
}

_______________________
General response fields
{
	"model": "name of model that was used."
	"created_at": "YYYY-mm-ddTHH:MM:SS.ffffffZ"
	"done": true/false,
	"done_reason": "stop",
	"context": [sequence, of, ints],

	"total_duration"      : int | nanoseconds to generate
	"load_duration"       : int | nanoseconds to load model
	"prompt_eval_count"   : int | number of prompt input tokens
	"prompt_eval_duration": int | nanoseconds to eval prompt
	"eval_count"          : int | number of output tokens
	"eval_duration"       : int | nanoseconds to output tokens

	"error": "error message"
	         NOTE: if "stream" and error occurs, then one of the newline-delimited json objects
	         will have the "error" field.

	"thinking": "thinking string",
	"logprobs": [
		{
			"token": "<string>",
			"logprob": 123,
			"bytes": [
				123
			],
			"top_logprobs": [
				{
					"token": "<string>",
					"logprob": 123,
					"bytes": [
						123
					]
				}
			]
		}
	]
}


____________
status codes
200: ok, success
400: bad request (missing params or invalid json)
404: model not found
429: rate limit exceeded
500: internal server error
502: bad gateway (can't reach cloud model)

-2.1.0.1-  /api/generate
========================
POST a prompt to get a response.
__________________
request parameters
{
	"prompt": "initial text",
	"suffix": "text between prompt and response",
	"images": [b64string,...]
	"system": "system prompt"
	"raw": true/false: raw response w/o prompt templating
}

___________________
response parameters
{
	"response": "",
}

-2.1.1-  python
===============
pip install ollama

import ollama

# Simple text generation
response = ollama.generate(
	model='gemma3:4b',
	prompt='Create a simple web scraper in Python using requests and BeautifulSoup'
)
print(response['response'])

# Conversational interface
chat_response = ollama.chat(
	model='gemma3:4b',
	messages=[
		{'role': 'system', 'content': 'description of what this model should be doing. "you are ..."'}
		{'role': 'user', 'content': 'What the user asks of the model'}
	]
)
print(chat_response['message']['content'])
