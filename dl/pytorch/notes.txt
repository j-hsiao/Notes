-1.2- Predefined modules

nn.Sequential(*Modules)
	run each module sequentially.

nn.Conv2d
	inchans=i, outchans=i, ksize=i|(i,i), stride=i|(i,i), padding=s|i|(i,i),
	dilation=i|(i,i), dilation=i|(i,i), groups=i, bias=b,
	padding_mode='zeros|reflect|replicate|circular',
	device=None,dtype=None

	In summary, this is just `outchans` conv kernels of shape (`inchans`, *ksize)
	for each kernel in params:
	conv2d(input, kernel[i]) -> output channel[i]

nn.Linear (linear transform, aka matrix multiply)
	inchans=i, outchans=i, bias=b, device=None, dtype=None

	linear transform (matmul) out = x @ A.T + b
	If input is viewed as row vectors, then
	A is an inchans x outchans matrix array
	b is an inchans array.

============
-5- training
============
Training involves running functions to calculate results,
calculate an error, and then running a backward step to calculate
derivatives, then an optimizer to perform updates.
Example:

```
import torch
from torchvision.models import resnet18, ResNet18_Weights
model = resnet18(weights=ResNet18_Weights.DEFAULT)
data = torch.rand(1, 3, 64, 64)
labels = torch.rand(1, 1000)
prediction = model(data)
loss = (prediction - labels).sum()
loss.backward()

optim = torch.optim.SBD(model.parameters(), lr=1e-2, momentum=0.9)
optim.step()
```

NOTE: if the tensor is NOT a scalar, then gradient is required,
which should just be (torch.ones(tensor.shape)) ???

NOTE: optim.zero_grad() before the first backward() and after
every step.  Optimizers with momentum will store the momentum in
their own separate buffers.

```
for epoch in epochs:
	for data, label in dataloader:
		optimizer.zero_grad()
		result = model(data)
		loss = LossFunc(result, label)
		loss.backward()
		optimizer.step()
```

-6.2- collective comm
=====================
scatter    : list items scattered to respective proc
gather     : from all procs to this proc into a list
reduce     : from all procs to this proc, opped together

broadcast  : same item to all procs
all-gather : everyone gets a list of everyone's item

def average_gradients(model):
    size = float(dist.get_world_size())
    for param in model.parameters():
        dist.all_reduce(
            param.grad.data, op = dist.reduce_op.SUM)
        param.grad.data /= size
